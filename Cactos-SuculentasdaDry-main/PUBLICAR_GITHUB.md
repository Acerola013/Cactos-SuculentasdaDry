# Cactos & Suculentas da DRY — publicação

## Antes de publicar
1. Abra `index.html`.
2. Procure `const WHATSAPP = '5516999999999';`.
3. Troque pelo número oficial do WhatsApp, somente números, com 55 + DDD + número.
4. Salve.

O Instagram já está configurado para `@suculentasdadry_`.

## GitHub Pages
1. Entre em https://github.com/ e crie um repositório público.
2. Dê um nome simples, por exemplo `cactos-suculentas-dry`.
3. Envie o conteúdo desta pasta para a raiz do repositório. O arquivo `index.html` precisa ficar na raiz.
4. Abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.
8. O GitHub mostrará a URL pública do site.

## Depois da publicação
- Abra a URL no computador e no celular.
- Teste ARRANJOS, CUIDADOS, SOBRE e CONTATO.
- Só depois gere o QR Code estático usando a URL `https://...` do GitHub Pages.

## Importante
O endereço `file:///C:/.../index.html` não deve ser usado no QR Code. Ele só funciona no computador onde o arquivo está salvo.
